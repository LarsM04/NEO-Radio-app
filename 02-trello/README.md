## Lijsten op het bord

| Lijst       | Betekenis                                   |
| ----------- | ------------------------------------------- |
| Backlog     | Alle taken die nog gedaan moeten worden     |
| To do       | Taken voor deze week / sprint               |
| Doing       | Waar iemand nu mee bezig is                 |
| Review      | Klaar, maar moet nog gecheckt worden        |
| Done        | Helemaal af                                 |

## Screenshots

`screenshots/` met de datum in de naam, bijv. `2026-10-07-trello.png`.
Zo kun je later laten zien hoe het project is verlopen.

# 04 – Ontwerp

Ons eigen ontwerp van de NEO Radio app, van eerste idee tot prototype.

| Map           | Wat hoort erin                                                  |
| ------------- | --------------------------------------------------------------- |
| `schetsen/`   | Eerste ideeën, foto's van papieren schetsen, moodboards         |
| `wireframes/` | Lo-fi wireframes van de schermen                                |
| `designs/`    | Uitgewerkte hi-fi schermen / exports uit Figma                  |
| `prototype/`  | Klikbare prototypes of een bestand met de link naar Figma       |

Tip: geef schermen een duidelijke naam met versienummer, bijv. `homescreen-v2.png`.

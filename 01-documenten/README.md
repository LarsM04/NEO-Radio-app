# 01 – Documenten

Alle documenten rondom de opdracht.

| Map                 | Wat hoort erin                                                        |
| ------------------- | --------------------------------------------------------------------- |
| `opdracht/`         | Briefing, opdrachtomschrijving, beoordelingscriteria, rubrics         |
| `plan-van-aanpak/`  | Plan van aanpak, planning, taakverdeling, samenwerkingscontract       |
| `notulen/`          | Aantekeningen van teammeetings en gesprekken met de opdrachtgever     |
| `presentaties/`     | Presentaties, pitches en tussentijdse opleveringen                    |
| `feedback/`         | Feedback van docenten, opdrachtgever en medestudenten                 |

Tip: zet een datum voor notulen en feedback, bijv. `2026-10-07-feedback-docent.pdf`.
